# 音乐叙事与创意转场 Implementation Plan

**Goal:** 交付60秒、1920×1080、45fps的宣传片、HTML预览和下载入口。

**Spec:** 最终反馈为：音乐与第一幕同时渐入；开场受骗个例、头像缩点、连续拉远成多人头像树状图；主要产品机制镜头保持清晰线条；18秒完整转折“但在转账前，还有核验这一步”，文字和环形光效加强力度；后半段展示成果、产品作用及造福人民的目标，压缩停顿。

**Architecture:** Remotion统一帧时间线，SVG人物和机制，局部粒子转场；前奏时长适配保持18秒鼓点，后半段原速度；HTML和MP4共用组件及音轨。

## 边界

七角色顺序固定，规则与人工节点不属于角色。只给建议，最终动作等待本人确认。规则拒绝编造证据、条款与无据结论，不拒绝转账。不虚构成功率、保护人数或挽损金额。人物树及个例标为示意，FTC金额标明美国及报告口径。
