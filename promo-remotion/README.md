## 连续叙事

开场长期骗局个例缩为头像，拉远构成2022/2023/2024三根年度损失柱。背景逐拍出现长期投资骗局、刷单返利、冒充客服、冒充公检法、熟人借款、虚假理赔六类情境。美国FTC消费者报告损失来源见STATISTICS.md，头像不代表真实受害人数。

18秒转折与音乐攻击音对齐；22.272—83.926秒由同一个持续挂载的SVG舞台承接。三段可疑消息依次滑入，原文线索进入案卷，案卷移动到七角色下方，角色按两拍节奏接力。案卷继续移到规则卡口前，已有引用通过，编造引用原路打回，再分出三档结论与本人确认，展开四条行动建议。

同一份案卷缩小并展开84个测试样本，样本分成66名正确指认与18名转人工；这些方块继续排成新旧管线对照，合规指认48→66、违规指认36→0，18名证据不足者移入人工复核行。24张无关引用依次进入规则节点并被打回，计数随每次测试递增。结尾不使用粒子转场，稳定呈现品牌与公益目标。

## 音乐

采用用户指定[《千年之后》参考视频音源](https://www.bilibili.com/video/BV1uiHs63Ev6/)，全程原速，无atempo。原有两拍前奏拼接保留，18秒转折不变，后续接原曲17.76秒起的72秒。音轨起音测得17.78秒，约0.5315秒一拍；主要动画节点按18.02+n×0.5315秒安排，再取整到45fps帧。详见MUSIC.md与src/music-cues.json。

## 事实边界

七角色只提供建议，规则节点和人工确认不计入AI角色。拒绝的是编造证据、条款及无据结论，不是支付交易；不展示银行接入或自动付款。成果属于PPT项目本地规则基线rules-baseline私有合成评测，v0.3.1-r7，2026-10-04，不作为七角色助手在真实用户中的防骗成功率。产品PNG保持原始哈希。旧整页场景组件保留为素材，最新后半段实际使用ContinuousStory。
