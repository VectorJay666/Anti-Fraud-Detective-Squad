# 留一步 · 逐镜配乐

为这支60秒、20镜、45fps宣传动画创作。保留轻电子脉冲、柔和电钢键音、温暖铺底及短空间回声，按画面安排和声、动机、重音与留白。

## 音乐结构

- **0—8秒：停顿与三种催转。** 开场留出呼吸；客服、返利、熟人三个场景使用同一音乐想法，改变回答音高。3.32／5.32／7.32秒的轻音对应蓝色路径抵达手机。
- **8—14秒：工具与材料。** 产品名出现时打开空间；材料输入分别出现，再以10.52、10.88秒的双音汇入案卷；真实界面使用温和展宽，不放冲击音。
- **14—24秒：交叉核验。** 三声回应对应前三位角色的路径，随后七音接力对应七角色，最后归到建议卷宗；三项建议以短下降音型呈现。
- **24—36秒：规则核对。** 转低音区；25.6秒闸线落定配主落锁，29.6和30.2秒给两处编造引用以短标记；31秒真实结果只有低沉回声，随后留白；规则与人工两关各有一次轻音。
- **36—48秒：人的决定与实用步骤。** 人工确认段撤去鼓点、转暖；本机链路三声轻音，四项行动四个清晰音，之后留空供阅读。回放处重现主题回声。
- **48—60秒：流程与品牌。** 五个流程节点推动五音动机，52.08秒曲线完成进入终止式；54秒稳定F6/9和声落定，此后不再新增节奏，59.2秒开始释放，在60秒内结束。

## 节奏与对位

底层120BPM网格让整秒镜头边界可对位；主要脉冲使用半速的60BPM，保持克制。34个画面提示点与55个键音／低频事件记录在 `public/assets/audio-report.json`，音频起点按45fps最近帧量化。七角色和行动清单的音符跟随实际显现时刻，不机械地套用连续鼓点。

旋律围绕D、A、F、E展开，和声使用D小调与F大调相关色彩。音色全部由程序合成，无外部音乐、语音或音色采样。

## 文件与复现

- 试听：`delivery/转账前保镖-专属配乐.mp3`。
- 视频／HTML使用：`public/assets/soundtrack.m4a`。
- 画面提示点：`src/music-cues.json`。
- 合成源码：`scripts/audio.py`，需要Python、NumPy与FFmpeg。
- 原始WAV：`public/assets/music-master.wav`，48kHz、16bit、立体声；由脚本生成，不纳入Git。
- 更新视频：`npm run replace-music`，完整复制视频流，仅替换音乐流。

没有加入人声、歌词、银行动作或成功庆祝音。规则段的低频只强调无据结论被拒绝，人工确认段保持平静。
