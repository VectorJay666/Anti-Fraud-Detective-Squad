# 音乐与画面对位

用户指定音源：[《千年之后》参考视频](https://www.bilibili.com/video/BV1uiHs63Ev6/)，上传者TimeGoTime；曲名来自用户确认及视频简介，不把上传者认定为作曲者。

全程原速、原音高，不使用atempo或重采样拉伸。从源0.8225秒起音；重复1.0625秒的两拍前奏一次，再接0.8225—17.76秒原片段，合计18秒。18秒后接源17.76秒开始的72秒。原攻击音17.78秒落到视频18.02秒，误差小于45fps的一帧。

源时间映射：视频0—1.0625秒为0.8225+t；1.0625—18秒为0.8225+t−1.0625；18秒后为17.76+t−18。首80毫秒淡入，画面首0.65秒同步渐入；总音量降低5dB，末1.1秒余弦淡出。48kHz双声道，192kbps AAC，90秒。

18秒转折保持不变。对源音轨18—88秒的5ms RMS起音增量进行周期匹配，得到约0.5315秒节拍间隔。源17.78秒攻击音对应视频18.02秒。主叙事节点选择18.02+n×0.5315，n为8/20/28/44/56/68/80/88/100/112/124，按45fps取整；七角色每两拍、测试引用每三分之一拍出现。末尾品牌进入83.926秒，90秒结束。

src/music-cues.json记录镜头与角色的准确帧号。原曲后半段保持连续播放，不通过改变速度来匹配时长。

复现：python scripts/reference_music.py <reference.m4a>，然后npm run render与npm run finalize。音频报告public/assets/audio-report.json包含源SHA256、首100ms RMS、峰值、原速说明。HTML、MP4均采用同一AAC；完整参考仅保存在本机缓存。
