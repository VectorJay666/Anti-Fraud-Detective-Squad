# 当前交付验收

规格：1920×1080、45fps、2700帧、60秒，立体声48kHz，无旁白、逐句字幕。

检查项目：
- 时间线20个逻辑段连续，18秒在第810帧转折，音乐首100ms有信号，未放慢。
- 长期骗局个例2.4秒后缩点，镜头拉远构成人物头像柱状图；三年高度按88/100/125比例，从零起。
- 七角色顺序不变，rule_gate和human_confirm不是AI角色；拒绝无据结论而非拒绝转账。
- 依据PPT增加三类场景、三档结论、证据编号回查、66/84与24/24量化测试画面；合成评测口径始终可见。
- 结尾没有粒子桥；59秒与2699帧稳定卡字节一致。
- 原始产品PNG的SHA256保持一致；当前时间线使用代码机制动画，PNG仍保留为素材。

验证命令：npm run check、npm run build、npm run stills；python scripts/contact_sheet.py生成总览与转场校验图。npm run finalize核验MP4规格、音视频60秒及音轨匹配，导出清单SHA256对应后启用HTML下载。
